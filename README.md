# PyLoan Approval System Using Logical Operators

PyLoan Approval System is a beginner-friendly Python mini project that determines whether a user is eligible for a loan using logical operators and conditional statements.

The program checks multiple conditions such as salary, age, employability status, payment history, and savings account details to decide the loan approval status.
